# synthpy
🎹 SynthPy Sintetizador polifónico de terminal. Sin DAW, sin navegador, sin instaladores. Solo Python3 + numpy + sounddevice. Corre en PC, celular con Termux o equipo viejo. ✅ 5 ondas, 16 voces, ADSR completo, filtro LP, 2 octavas ✅ UI en tiempo real Ligero, libre y tuyo. Tu código, tu sonido. 🔥
